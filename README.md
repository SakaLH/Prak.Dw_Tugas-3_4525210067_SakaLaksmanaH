# PROFIL MAHASISWA

## Deskripsi

Project ini merupakan hasil praktikum Pertemuan 03 mengenai pengenalan CSS. Pada praktikum ini dibuat halaman profil mahasiswa menggunakan HTML dan CSS.

Halaman web dibuat berdasarkan contoh Curriculum Vitae dengan penerapan external CSS. File HTML dihubungkan dengan file `style.css` untuk mengatur tampilan halaman, seperti warna, ukuran teks, jarak, tata letak, border, dan tampilan gambar.

## Struktur Folder

```text
PERTEMUAN-03/
├── index.html
├── css/
│   └── style.css
└── images/
    └── profil.jpg
```

## Fitur

Profil mahasiswa
Foto profil
Informasi pendidikan
Daftar keahlian
Informasi kontak
Footer
External CSS
Penggunaan berbagai format warna CSS

# Mini Style Guide

## Font

Font utama: Arial, Helvetica, sans-serif
Ukuran teks utama: 16px
Ukuran judul utama (H1): 32px
Ukuran subjudul (H2): 24px

## Warna

Warna utama: #003366
Warna aksen: #006699
Warna teks: #333333
Warna footer: navy

## Spacing

Padding header: 30px
Padding konten utama: 30px
Margin konten utama: 30px
Line-height: 1.7

## Elemen Visual

Foto profil berbentuk lingkaran
Border foto: 4px solid white
Border heading: 2px solid #006699
Background halaman: #F2F6FA

/* HEX */

rgb(0, 102, 153)
